Gold & Silver Prices India - static web app (single file: index.html)

Features: live 24K/22K/18K gold and silver prices in INR, city-wise rates for
24 Indian cities (estimated from the live national rate), price calculator,
light/dark theme.

Deploy (any static host):
- Netlify: app.netlify.com/drop -> drag this folder
- Vercel / Cloudflare Pages / GitHub Pages: upload this folder, no build command, output directory = root
Live data: gold-api.com (XAU, XAG in USD/oz) + open.er-api.com (USD/INR). No API keys needed.
